## 概要

睡眠時間を記録し、ざっくりとした睡眠負債を可視化するカレンダーアプリです。

## できること

- 日次記録
- 週次合計
- 端末内保存
- 低開発コスト商品

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
