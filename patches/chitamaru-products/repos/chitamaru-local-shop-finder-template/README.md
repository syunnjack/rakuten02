## 概要

地域の店舗・スポットを調べてまとめるための探し方・掲載テンプレートです。

## できること

- 調査手順
- 掲載項目
- カテゴリ例
- machi-list資産の製品化

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
