## 概要

市区町村単位の賃料相場をウォッチし、変動を追う個人向け月額サービス案です。

## できること

- エリア登録
- 月次比較の型
- 転居検討向け
- 価格ウォッチの居住版

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
