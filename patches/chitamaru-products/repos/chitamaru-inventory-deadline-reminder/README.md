# 保管・出品期限リマインダー

知多丸（Chitamaru）商品 — おすすめ順 **#23**（ID: B3）

- 価格目安: **¥380/月**（形態: M）
- BOOTH（予定）: https://chitamaru.booth.pm/items/inventory-deadline-reminder
- ストア: https://syunnjack.dev/store
- カテゴリ: せどり・買取・在庫

## 概要

保管期限・出品期限を登録し、通知で回転を促すせどり向け月額リマインダーです。

## できること

- 期限登録
- 通知想定
- SKUメモ
- 在庫回転改善

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
