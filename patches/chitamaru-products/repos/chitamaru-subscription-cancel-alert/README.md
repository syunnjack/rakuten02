## 概要

サブスクの更新日を登録し、解約忘れを防ぐ個人向けリマインダーです。

## できること

- 更新日リマインド
- 金額メモ
- カテゴリ分け
- 家計ツールと併売向き

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
