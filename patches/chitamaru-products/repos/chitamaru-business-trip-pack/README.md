## 概要

出張時の終電条件とビジネスホテルの希望条件を保存し、毎回の探し直しを減らす月額パックです。

## できること

- 条件保存
- 終電ウォッチ
- 予算帯メモ
- 個人事業主向け

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
