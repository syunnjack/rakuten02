## 概要

テーマを入れるとX（Twitter）スレッドの構成案を生成するツールです。

## できること

- 投稿分割案
- フック文案
- コピー
- 個人開発の集客向け

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
