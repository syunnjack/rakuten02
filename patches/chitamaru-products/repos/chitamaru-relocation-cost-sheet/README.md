# 地方移住コスト試算シート

知多丸（Chitamaru）商品 — おすすめ順 **#43**（ID: F6）

- 価格目安: **¥580**（形態: B）
- BOOTH（予定）: https://chitamaru.booth.pm/items/relocation-cost-sheet
- ストア: https://syunnjack.dev/store
- カテゴリ: 不動産・投資

## 概要

引っ越し・家賃差・交通・生活費など、地方移住のコストを試算するシートです。

## できること

- 費用カテゴリ
- 月次/初期の分け
- 比較メモ
- 話題性のあるニッチ

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
