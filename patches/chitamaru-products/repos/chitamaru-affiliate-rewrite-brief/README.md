## 概要

テーマと現状課題を入れると、アフィ記事のリライト指示書を生成するツールです。

## できること

- 指示書自動生成
- 検索意図欄
- CTA設計
- content-brief姉妹

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
