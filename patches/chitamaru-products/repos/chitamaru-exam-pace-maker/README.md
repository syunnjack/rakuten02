- 試験日カウントダウン

- クイズアプリ連携想定

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）

3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ
