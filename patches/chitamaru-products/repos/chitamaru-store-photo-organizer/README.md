店舗せどりで撮った写真を日付・店舗・JANで整理するためのフォルダルールと補助スクリプトです。

## できること

- 命名規則
- フォルダ雛形
- 整理スクリプト例
- 出品前の時短

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
