# JAN一括→メルカリ下書き文生成

知多丸（Chitamaru）商品 — おすすめ順 **#25**（ID: B7）

- 価格目安: **¥1,480**（形態: B）
- BOOTH（予定）: https://chitamaru.booth.pm/items/jan-mercari-draft
- ストア: https://syunnjack.dev/store
- カテゴリ: せどり・買取・在庫

## 概要

JANや商品名の一覧からメルカリ向け下書き文を一括生成するツールです。

## できること

- CSV/手入力対応
- 文面テンプレ
- コピー出力
- 出品ボトルネック解消

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
