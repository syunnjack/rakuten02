# せどり確定申告メモ帳

知多丸（Chitamaru）商品 — おすすめ順 **#5**（ID: B6）

- 価格目安: **¥780**（形態: B）
- BOOTH（予定）: https://chitamaru.booth.pm/items/resale-tax-notebook
- ストア: https://syunnjack.dev/store
- カテゴリ: せどり・買取・在庫

## 概要

せどりの仕入・売上・経費を年次で残し、確定申告前の整理をラクにするスプレッドシートテンプレートです。

## できること

- 月次入力→年次集計
- 経費カテゴリ付き
- 年末アップデート想定
- CSV雛形同梱

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
