# 店舗別 今日の仕入れルートマップ

知多丸（Chitamaru）商品 — おすすめ順 **#22**（ID: B1）

- 価格目安: **¥580**（形態: B）
- BOOTH（予定）: https://chitamaru.booth.pm/items/resale-store-route-map
- ストア: https://syunnjack.dev/store
- カテゴリ: せどり・買取・在庫

## 概要

今日回る買取・仕入れ店舗の順序とメモを残すルートマップテンプレートです。

## できること

- 店舗リスト
- ルート順
- 仕入メモ
- 日次利用

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
