# 赤字SKU 自動フラグシート

知多丸（Chitamaru）商品 — おすすめ順 **#54**（ID: B8）

- 価格目安: **¥580**（形態: B）
- BOOTH（予定）: https://chitamaru.booth.pm/items/loss-sku-flag-sheet
- ストア: https://syunnjack.dev/store
- カテゴリ: せどり・買取・在庫

## 概要

仕入と売価から赤字・滞留SKUにフラグを立てる在庫管理シートです。

## できること

- 利益フラグ
- 滞留日数
- 処分候補リスト
- 回転改善

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
