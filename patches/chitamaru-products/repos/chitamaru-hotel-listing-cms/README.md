## 概要

ホテル掲載枠を運用するための店舗ページCMSと簡易計測のスターターです。

## できること

- 店舗CRUDの型
- 計測イベント案
- 公開ページ雛形
- H1の実装基盤

## 使い方

1. このリポジトリをクローン（または BOOTH で購入した ZIP を解凍）
2. `README` と `docs/` / `app/` を確認
3. テンプレートはそのままコピー、ツールは `app/index.html` を開くか静的ホストへデプロイ

## 開発

```bash
# 静的ツールの場合
open app/index.html
# or
npx --yes serve app
```
