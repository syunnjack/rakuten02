# 副業アフィリエイト 週次収支ログブック — スプレッドシート設計書

Google スプレッドシートで以下の構成を実装します。

---

## シート 1: 週次入力

| 列 | 内容 |
|----|------|
| A | 週（例: `2026-W33`） |
| B | 開始日（例: `2026-08-10`） |
| C | ASP名（楽天 / Amazon / A8 / もしも / バリューコマース 等） |
| D | クリック数 |
| E | 承認件数 |
| F | 売上金額（円） |
| G | 報酬金額（円） |
| H | 主なコンテンツ |
| I | 今週やったこと |
| J | 来週やること |

---

## シート 2: 月別・ASP別 自動集計

`SUMIFS` で週次入力を月・ASPごとに集計します。

```
=SUMIFS(週次入力!G:G, 週次入力!C:C, A2, TEXT(週次入力!B:B,"YYYY-MM"), TEXT($B$1,"YYYY-MM"))
```

---

## シート 3: コンテンツ別貢献度

| 列 | 内容 |
|----|------|
| A | コンテンツ名（記事タイトル or SNS投稿URL） |
| B | チャネル（ブログ / Twitter / Instagram / YouTube 等） |
| C | 累計クリック数 |
| D | 累計報酬（円） |
| E | 1クリック単価（=D/C） |
| F | 直近の施策メモ |

---

## シート 4: ダッシュボード（グラフ）

- 月別報酬推移（折れ線グラフ） — 週次入力から集計
- ASP別報酬シェア（円グラフ） — 当月分
- チャネル別クリック数比較（棒グラフ） — コンテンツ別シートから

---

## 運用フロー

1. 毎週月曜 → 前週のデータを「週次入力」に追加（5分）
2. 施策メモを「今週やったこと」に書き残す
3. 月末にダッシュボードで振り返り → 来月の強化コンテンツを決定
