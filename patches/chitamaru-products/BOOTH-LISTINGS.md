# BOOTH出品パッケージ（知多丸 / chitamaru.booth.pm）

未出品商品の**出品文・価格・納品物・購入者メッセージ・チェックリスト**を、BOOTH管理画面にコピペできる形でまとめたものです。

ショップ: `https://chitamaru.booth.pm`  
ストア導線: `https://syunnjack.dev/store`

---

## 出品の進め方（共通）

1. BOOTH管理画面 → 商品を追加
2. 下記の「商品名 / 価格 / 説明 / タグ」を貼る
3. 納品ファイル（ZIP または 合言葉・コピーURL）を用意
4. **下書き保存 → プレビュー確認 → 公開**
5. 公開後、URLが `https://chitamaru.booth.pm/items/{数字ID}` になる場合がある  
   → `syunnjack.dev/store` の `boothUrl` を**実URLに差し替え**て再デプロイ
6. 購入テスト（自分で1円商品 or クーポンで確認）→ 自動メッセージが届くか確認
