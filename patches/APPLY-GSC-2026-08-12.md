# GSC 改善パッチ適用手順 — 2026-08-12

本リポジトリの `cursor` トークンでは他リポジトリへ push できないため、
各サイト向け修正は `patches/` に同梱しています。Windows ローカルで順に適用してください。

## 1. shudenhotel.jp（本リポジトリ）

PR: https://github.com/syunnjack/rakuten02/pull/34

マージ後 Render が再デプロイしたら:

```powershell
curl.exe -s https://shudenhotel.jp/ | findstr canonical
curl.exe -s https://shudenhotel.jp/sitemap.xml | findstr /C:"search?"
curl.exe -sI https://shudenhotel.jp/shudenhotelindex2026.txt
```

Search Console で `https://shudenhotel.jp/sitemap.xml` を再送信。

## 2. busselect.jp

```powershell
cd C:\Users\syunn\source\repos\kousokubus-benri
curl.exe -L -o gsc-0005.patch "https://github.com/syunnjack/rakuten02/raw/cursor/gsc-site-performance-86e1/patches/kousokubus-benri/0005-Reject-placeholder-GA4-GSC-and-fix-title.patch"
git am gsc-0005.patch
git push origin main
```

Site Creator で実値を設定（日本語プレースホルダを削除）:

| Key | Value |
|-----|-------|
| `NEXT_PUBLIC_GOOGLE_ANALYTICS_MEASUREMENT_ID` | `G-...` |
| `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` | HTML タグの content |

再デプロイ後 Search Console で sitemap 再送信。
