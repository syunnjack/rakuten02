## 0. 推奨: GitHub Actions（CROSS_REPO_PAT）

1. GitHub → rakuten02 → Settings → Secrets → `CROSS_REPO_PAT`  
   （classic PAT、対象4リポジトリへの `repo` 権限）
2. Actions → **Apply GSC patches to site repos** → Run workflow
3. 各リポジトリに PR が開くのでマージ＆デプロイ

CLI 同等:

```bash
export CROSS_REPO_PAT=ghp_xxx
bash scripts/site-analytics/apply-gsc-patches.sh
```
