## 出品手順（再掲）

1. ショップ管理 → 商品登録 → **デジタルデータ販売**
2. 上記の商品名・説明を貼る
3. 対応する `.md` をアップロード（必要ならZIP化）
4. **公開**
5. 商品URLをコピーしてサイト環境変数へ

```bash
NEXT_PUBLIC_BOOTH_SHOP_URL=https://xxxxx.booth.pm
NEXT_PUBLIC_BOOTH_ITEM_NOTES_URL=https://xxxxx.booth.pm/items/........
NEXT_PUBLIC_BOOTH_ITEM_CHECKLIST_URL=https://xxxxx.booth.pm/items/........
NEXT_PUBLIC_BOOTH_ITEM_SUPPORT_URL=https://xxxxx.booth.pm/items/........
```
