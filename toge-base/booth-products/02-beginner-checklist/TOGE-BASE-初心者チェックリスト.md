# 【TOGE BASE】壁接触を減らす初心者チェックリスト

ファン運営サイト TOGE BASE の任意購入コンテンツです。  
公式ではありません。ゲームメーカー／権利者各社とは関係ありません。

更新目安: 2026-08-12  
サイト: https://togepass.jp/

---

## 使い方（5分）

1. プレイ前に「今回の目標」を1つだけ選ぶ
2. プレイ後にチェックを付ける
3. 3回連続で達成できたら次の段階へ

目標はタイムより先に **壁接触ゼロ完走** を推奨します。

---

## 段階0｜乗る前

- [ ] ハンドル・ペダルの遊びを数秒確認した
- [ ] 今日のコースを1つに決めた（最初は秋名山が無難）
- [ ] 車種を1台に固定した（AE86 / EG6 推奨）
- [ ] 「速さ」より「接触を減らす」と決めた

---

## 段階1｜基礎姿勢（最初の10周）

- [ ] コーナー前に視線を先へ送れている
- [ ] 急ハンドルを減らせている
- [ ] アクセルを踏んだまま突っ込んでいない
- [ ] 出口まで車の姿勢を意識できている
- [ ] 1周でも壁接触ゼロで完走できた

### できたら次へ
段階1が3セッション連続で半分以上チェックできたら段階2へ。

---

## 段階2｜進入の安定

- [ ] 進入前にイン寄せを終わらせている
- [ ] アクセルオフの長さが短く安定している
- [ ] 同じコーナーで同じ失敗を繰り返していない
- [ ] 上り／下りを分けて記録している
- [ ] 壁接触ゼロ完走が連続2回できた

---

## 段階3｜碓氷などヘアピンへ

- [ ] ヘアピン手前で十分な減速ができている
- [ ] イン寄せすぎによるアンダーを減らせている
- [ ] 連続ヘアピンでも視線が止まらない
- [ ] 車種ごとのブレーキングポイントをメモした
- [ ] 壁接触ゼロ完走が連続3回できた
