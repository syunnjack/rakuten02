# BOOTH商品データ

このフォルダは TOGE BASE のBOOTH出品用デジタルコンテンツです。

| フォルダ | 商品 |
|----------|------|
| `01-pass-notes/` | 秋名・碓氷 練習メモセット |
| `02-beginner-checklist/` | 初心者チェックリスト |
| `03-support-pack/` | 運営応援パック |
| `BOOTH出品文面.md` | 商品名・説明のコピー用 |

## 使い方

1. `BOOTH出品文面.md` の文面をBOOTHに貼る
2. 各フォルダの `.md` を商品ファイルとしてアップロード
3. 公開後のURLをサイトの環境変数へ設定

必要なら `.md` をZIPにまとめてからアップロードしても構いません。
