# 【TOGE BASE】秋名・碓氷 練習メモセット（デジタル）

更新目安: 2026-08-12

## このメモの使い方

1. プレイ前に「今日の1テーマ」を1つ決める
2. 上り／下りを分けて記録する
3. 壁接触ゼロが続いたら、次のテーマへ進む
4. タイムより先に「姿勢の安定」を優先する

---

## A. 秋名山メモ

### テーマ
ブラインドを先読みし、短いアクセルオフで姿勢を作る。

### 進入チェック
- [ ] コーナー先のガードレールを先に見る
- [ ] イン寄せは進入前に終わらせる
- [ ] アクセルオフは短く、踏んだまま突っ込まない
- [ ] 出口でトラクションを戻してから加速

### よくあるミス
| 症状 | 原因の目安 | 直し方 |
|------|------------|--------|
| 壁に寄る | 視線が手前 | ガードレール先端を見る |
| 出口が遅い | オフが長い／インが遅い | オフを短くし、進入前に寄せる |
| 姿勢が崩れる | 急ハンドル | 舵角を小さく、早めに戻す |

### 練習メニュー（秋名）
1. 上り 5周: 壁接触ゼロだけを目標
2. 下り 5周: 進入地点を固定して比較
3. 通し 3周: 「視線 → オフ → 出口」の順を声に出す

### 1行メモ欄
```
日付:
車種:
上り接触:
下り接触:
今日の改善:
次の課題:
```

## B. 碓氷峠メモ

### テーマ
ヘアピンの減速精度。進入を欲張らず、出口で立て直す。

### 進入チェック
- [ ] ヘアピン手前で十分な減速
- [ ] インに寄せすぎてアンダーを誘発しない
- [ ] 短いコーナーでも視線を先へ送る
- [ ] 車種ごとにブレーキングポイントを固定

### よくあるミス
| 症状 | 原因の目安 | 直し方 |
|------|------------|--------|
| 失速 | 進入が遅すぎる | 出口速度を意識した進入へ |
| アンダー | イン寄せが早い | 寄せは減速後、姿勢が立ってから |
| 連続で崩れる | 視線が止まり | 次のヘアピンを先に見る |

### 練習メニュー（碓氷）
1. ヘアピン単体 10本: 進入速度を段階的に上げる
2. 同じ車種で上下比較を記録
3. 壁接触ゼロ完走ができてから攻める

### 1行メモ欄
```
日付:
車種:
進入の感覚 (遅い/ちょうど/速い):
接触箇所:
出口の安定:
次の課題:
```

---

## C. 共通・今日の1テーマ例

- 視線をコーナー先に置く
- アクセルオフを短くする
- ブレーキングポイントを固定する
- 出口までハンドルを戻しきる
- 壁接触ゼロで完走する
