# 商品開発戦略 — 個人下地 → B2B

最終目標は **B2B（店舗・事務所の導入・掲載課金）**。  
先に個人向けで「誰が・何のために・いくら払うか」とレビュー実績を作る。

## 3段階

| Phase | 何を売るか | 価格帯 | 目的 |
|-------|------------|--------|------|
| 1 今 | 個人・買い切り（BOOTH） | ¥580 / ¥980 / ¥2,480 / ¥3,800 | 収入基盤・レビュー・改善サイクル |
| 2 次 | 個人・月額（通知） | ¥580 / ¥980 / ¥2,480 | 継続率でニーズ検証 |
| 3 目標 | B2B 掲載・導入・運用 | ¥2,480〜 / SaaS ¥3,800〜 | 単価アップ |

月額は Phase 1 の買い切りが回ってから **1本ずつ**（既存方針の終電ホテル Pro を崩さない）。
