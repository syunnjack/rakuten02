# SEO Dashboard Agency（SEO管理ダッシュボード Agency）

知多丸の**独立製品リポジトリ**です。既存プロトタイプを商品化するために新規作成しています。

- おすすめ順: **#15**
- Phase: **3**（1=個人買い切り下地 / 2=個人月額 / 3=B2B）
- 価格: 個人 **¥3,800** ／ 月額目安 ¥9,800〜 ／ B2B 複数顧客 Agency ¥9,800〜
- BOOTH（予定）: https://chitamaru.booth.pm/items/seo-dashboard-agency
- Pages: https://syunnjack.github.io/chitamaru-seo-dashboard-agency/

## 誰向け

複数サイト／複数顧客のSEOを見る個人と制作会社

顧客ごとの順位・指摘・月次レポを1画面に。

## できること

- 複数顧客カード
- 仮想の順位・流入サマリー
- 指摘チケット
- 月次レポート下書き

## 開発

```bash
npm install
npm run dev
npm run build
```

GitHub Pages は `base: '/chitamaru-seo-dashboard-agency/'` です。リポジトリの Pages を GitHub Actions に設定してください。

## 既存リポを上書きしない理由

同名のプロトタイプ（例: `seo-dashboard-agency`）が既にある場合でも、**商品名・価格・BOOTH導線・Phase 設計を持った製品版**として別リポにしています。
