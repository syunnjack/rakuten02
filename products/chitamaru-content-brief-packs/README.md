# Content Brief Packs（業界別コンテンツブリーフ素材集）

知多丸の**独立製品リポジトリ**です。既存プロトタイプを商品化するために新規作成しています。

- おすすめ順: **#14**
- Phase: **1**（1=個人買い切り下地 / 2=個人月額 / 3=B2B）
- 価格: 個人 **¥580** ／ 月額目安 シリーズ追加 ¥580 ／ B2B 制作会社向けセット
- BOOTH（予定）: https://chitamaru.booth.pm/items/content-brief-packs
- Pages: https://syunnjack.github.io/chitamaru-content-brief-packs/
- プロトタイプ: https://github.com/syunnjack/content-brief-engine

## 誰向け

不動産／転職／飲食の記事を量産したい個人

業界別テンプレで、ブリーフをすぐ書き出せる。

## できること

- 不動産・転職・飲食の3パック
- 見出し・検索意図・CTAの雛形
- コピー出力
- シリーズ追加販売

## 開発

```bash
npm install
npm run dev
npm run build
```

GitHub Pages は `base: '/chitamaru-content-brief-packs/'` です。リポジトリの Pages を GitHub Actions に設定してください。

## 既存リポを上書きしない理由

同名のプロトタイプ（例: `content-brief-packs`）が既にある場合でも、**商品名・価格・BOOTH導線・Phase 設計を持った製品版**として別リポにしています。
