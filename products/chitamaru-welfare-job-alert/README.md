# Welfare Job Alert（福祉系求人通知）

知多丸の**独立製品リポジトリ**です。既存プロトタイプを商品化するために新規作成しています。

- おすすめ順: **#7**
- Phase: **1**（1=個人買い切り下地 / 2=個人月額 / 3=B2B）
- 価格: 個人 **¥980** ／ 月額目安 求職者 ¥980 / 事業所 ¥2,480 ／ B2B 事業所掲載 ¥2,480〜
- BOOTH（予定）: https://chitamaru.booth.pm/items/welfare-job-alert
- Pages: https://syunnjack.github.io/chitamaru-welfare-job-alert/
- プロトタイプ: https://github.com/syunnjack/welfare-job-alert

## 誰向け

障害者雇用・福祉領域の就職／採用

福祉・障害者雇用に特化した条件一致だけを追う。

## できること

- 職種・雇用形態・配慮条件
- 事業所シードの一致表示
- 求職者ウォッチ
- 事業所掲載枠（準備）

## 開発

```bash
npm install
npm run dev
npm run build
```

GitHub Pages は `base: '/chitamaru-welfare-job-alert/'` です。リポジトリの Pages を GitHub Actions に設定してください。

## 既存リポを上書きしない理由

同名のプロトタイプ（例: `welfare-job-alert`）が既にある場合でも、**商品名・価格・BOOTH導線・Phase 設計を持った製品版**として別リポにしています。
