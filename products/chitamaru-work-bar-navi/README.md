# Work Bar Navi（夜のお店／仕事／エリアナビ）

知多丸の**独立製品リポジトリ**です。既存プロトタイプを商品化するために新規作成しています。

- おすすめ順: **#5**
- Phase: **1**（1=個人買い切り下地 / 2=個人月額 / 3=B2B）
- 価格: 個人 **¥980** ／ 月額目安 掲載 ¥2,480 ／ B2B 掲載パッケージ ¥2,480〜（運用代行可）
- BOOTH（予定）: https://chitamaru.booth.pm/items/work-bar-navi
- Pages: https://syunnjack.github.io/chitamaru-work-bar-navi/
- プロトタイプ: https://github.com/syunnjack/work-bar-navi

## 誰向け

夜勤・短時間・飲み／仕事導線をまとめたい層

エリア×業態で、夜の仕事とお店を一本のナビにする。

## できること

- エリア・業態フィルター
- 求人／店舗カード
- スポンサー枠のプレースホルダ
- 送客・掲載課金の導線

## 開発

```bash
npm install
npm run dev
npm run build
```

GitHub Pages は `base: '/chitamaru-work-bar-navi/'` です。リポジトリの Pages を GitHub Actions に設定してください。

## 既存リポを上書きしない理由

同名のプロトタイプ（例: `work-bar-navi`）が既にある場合でも、**商品名・価格・BOOTH導線・Phase 設計を持った製品版**として別リポにしています。
