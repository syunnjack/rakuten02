## 誰向け

地域の開店閉店速報を追う生活者＋露出したい店舗

近所の開店・閉店を、UGCと通知で速報する。

## できること

- 地域の開店／閉店シード
- UGC投稿（ローカル保存）
- ウォッチ
- 店舗掲載・スポンサー枠

## 開発

```bash
npm install
npm run dev
npm run build
```

GitHub Pages は `base: '/chitamaru-open-close-radar/'` です。リポジトリの Pages を GitHub Actions に設定してください。

## 既存リポを上書きしない理由

同名のプロトタイプ（例: `open-close-radar`）が既にある場合でも、**商品名・価格・BOOTH導線・Phase 設計を持った製品版**として別リポにしています。
